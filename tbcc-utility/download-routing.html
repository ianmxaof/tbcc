Download routing (circuit board)

Route any browser download — not just TBCC's own — into a Downloads subfolder based on file type, source domain, MIME type, or a URL pattern. Rules run top to bottom; the first match wins. Chrome only allows routing inside your default Downloads folder (no absolute paths, no drives) — this always builds a subfolder under it.
