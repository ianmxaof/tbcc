# TBCC Utility

Private distribution tree (v1.42.0).

## Plugins
Extension-only packages: upload `plugin.json` + `main.js` (or a `.user.js` port) in Options → Plugins.
Site tools is core-only; installed plugins appear under that menu.

## Sideload
1. Unzip release or clone
2. chrome://extensions → Developer mode → Load unpacked → `tbcc-utility/`
